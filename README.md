# Козырёк 19,5×2,4 м — расчёт консольной фермы

Проверочный расчёт фермы-клина из трубы 40×40×4 (чертёж ХХХХ.301231.01.01.01.000) как плоской рамы с жёсткими узлами.

- `index.html` — калькулятор в браузере, без зависимостей. Помимо фермы считает прогоны верха, настил, лист 2 мм, проушину по чертежу, опорную пластину, анкеры и сварной шов пояс/стойка — под каждой цифрой формула с подстановкой. Кнопки «Узел по чертежу» / «Узел по эскизу» переключают вариант крепления. Меняются шаг ферм, снег (Sg, μ), геометрия, сталь, крепление к стене; выводятся усилия по стержням, проверки по прочности и устойчивости (СП 16.13330.2017), прогиб торца (СП 20.13330.2016 прил. Д), усилия на анкеры и схема фермы с раскраской по использованию. Экспорт в CSV.
- `frame.py`, `results.py` — та же модель на Python (numpy), из неё взяты цифры для отчёта.

## Опубликовать на GitHub Pages

1. Создать репозиторий, залить эти файлы в корень (`index.html` должен лежать в корне или в `/docs`).
2. Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)` → Save.
3. Через минуту страница откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Локально: просто открыть `index.html` в браузере (шрифт Golos подтягивается с Google Fonts, без сети — системный).

## Что не учтено

Ветер (для этого козырька не определяет), раскрепление ферм из плоскости, узлы и сварные швы, проушины крепления (уголок 65×50×5 — не проходит, нужна опорная пластина). Оценка для постановки задачи, не заменяет КМ с расчётом по фактическим исходным данным.
